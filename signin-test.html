Python Jeopardy: Sign-in Test

This page checks two things before we build the online game: can a school Google account sign in, and can this device reach Firebase on the school network? Nothing is saved.

Setup needed (teacher, one time)

This page doesn't have your Firebase settings yet. Do these steps once, then refresh.

  1. Go to console.firebase.google.com, sign in with your Google account, and create a project (Google Analytics can be turned off).
  2. Build → Authentication → Get started → Sign-in method → Google. Turn it on, pick your email as the support email, and save.
  3. Still in Authentication: Settings → Authorized domains → Add domain. Add your GitHub Pages domain, for example yourname.github.io.
  4. Build → Realtime Database → Create database. Pick the location closest to you and choose locked mode.
  5. Click the gear icon → Project settings → General → Your apps → the web icon </>. Register the app (skip Firebase Hosting) and copy the firebaseConfig block.
  6. Open signin-test.html, find FIREBASE_CONFIG near the bottom, and paste your values in. Upload it to GitHub Pages.
